# Shared classroom instructions

Read `AGENTS.md`, then `.agents/skills/opengl-composite/SKILL.md`.
Use that one shared workflow; do not create a second divergent skill.
For a long calculation read `docs/background.md` and check whether this Claude
Code session exposes one-shot scheduling tools. Do not use a cloud routine for
local files, and do not assume a scheduler keeps running after Claude is closed.
After completing and pushing any work, always log a concise summary (what was built
or changed, key files, verification results, commit hash) on a GitHub Issue (`gh issue`)
per `AGENTS.md`.
